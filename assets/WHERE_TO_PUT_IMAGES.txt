LUMIÈRE — Asset Placement Guide
================================

Drop your generated images/video into the matching paths below.
The website will automatically show them when files are present.

-------------------------------------------------
  assets/hero/hero.mp4              ← looping hero video (5-10 sec)
  assets/hero/hero-fallback.jpg     ← 4K still image fallback (for mobile)

TIPS
----
- Use JPG for photos (smaller file size, faster load)
- Keep file names exactly as listed above (case-sensitive)
- Compress images before uploading (use squoosh.app for free)
- The website works right now without images — placeholders are shown
